 Limit      limit the number of returned records (Select * From ... where ... Limit 5) max num of returned rows is 5'
            offset (optional) , offset can be used after the Limit to specify Where to start counting the rows
            (ex: u have these rows returned from "Select * ... Limit 5" )
             row 0, row 1, row 2, row 3, row 4    u have these five rows 
              Limit 5 offset 1

              row 1,row 2,row 3, row 4. row 5   (row 0 is gone! cuz we started counting from row 1 (offset 1))
